📱 O que é o Meudin
O Meudin é um aplicativo de gestão financeira pessoal e compartilhada, focado em simplicidade, controle real de gastos e colaboração entre pessoas que dividem finanças — como casais, famílias, sócios ou pequenos negócios.
O objetivo central do app é permitir que o usuário entenda para onde o dinheiro está indo, tome decisões melhores e mantenha organização financeira sem complexidade excessiva.

🎯 Problema que o Meudin resolve
Falta de visibilidade sobre gastos e receitas
Dificuldade de controlar finanças compartilhadas
Apps financeiros muito complexos ou engessados
Pouca personalização de carteiras e categorias
Falta de visão histórica clara (filtros, gráficos, períodos)
O Meudin resolve isso oferecendo controle manual consciente, com dados claros, visualizações simples e colaboração entre usuários.

🧩 Principais conceitos do app
🔹 Carteiras
Representam “contextos financeiros” (ex: Pessoal, Empresa, Viagem, Projeto)
Podem ser compartilhadas com outros usuários
Possuem permissões (owner / membro)
🔹 Transações
Entradas e saídas
Sempre associadas a:
uma carteira
um usuário
uma categoria
Registro manual na primeira versão
🔹 Categorias de gastos
Padronizadas (alimentação, transporte, saúde, etc.)
Usadas para análise, gráficos e relatórios
Base para insights futuros e monetização por dados agregados

📊 Funcionalidades principais
Core (essenciais)
Cadastro e login de usuários
Criação e gerenciamento de carteiras
Compartilhamento de carteiras
Registro de receitas e despesas
Visualização de saldo, entradas e saídas
Gráficos por categoria
Filtros por período
Premium (monetização)
Múltiplas carteiras
Mais membros por carteira
Filtros avançados (histórico maior)
Exportação de dados (PDF / Excel)
Relatórios mais detalhados
Futuro: insights inteligentes e alertas

🏗️ Arquitetura resumida
Frontend: Flutter
Banco principal: Supabase (PostgreSQL)
Auth e dados financeiros: Supabase
Cobrança e planos: (indefinido)
API / lógica: Node js (Render)
Arquitetura pensada para:
Escalar gradualmente
Manter custos baixos no início
Separar dados financeiros de dados de cobrança

💰 Modelo de negócio
Freemium
Maioria dos usuários no plano gratuito
Receita vinda de:
Assinaturas (minoria, ~5–10%)
No futuro: dados agregados e parcerias, mkt/anuncios direcionados para usuarios compativel com seus gastos (ia?)
O foco não é extrair o máximo do usuário, mas criar valor suficiente para justificar o plano premium.

🧠 Visão de longo prazo
O Meudin pode evoluir para:
Plataforma de insights financeiros
Base de dados de comportamento financeiro (anonimizado)
Ferramenta útil tanto para pessoas físicas quanto pequenos negócios
Produto com forte apelo de recorrência
